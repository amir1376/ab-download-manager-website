## Instalacja

Możesz zainstalować AB Download Manager w następujący sposób

### Pobierz bezpośrednio

- [Oficjalna strona](https://abdownloadmanager.com/#download): Pobierz najnowszą stabilną wersję bezpośrednio. To jest najprostszy sposób dla większości użytkowników.
- [GitHub Releases](https://github.com/amir1376/ab-download-manager/releases/latest): Zawiera instalatory oraz pełną historię wydań.

### Skrypt instalacyjny

#### Linux (zalecane)
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amir1376/ab-download-manager/master/scripts/install.sh)
```

### Menedżer pakietów

#### Windows

##### Winget

```bash
winget install amir1376.ABDownloadManager
```

##### Scoop:

```bash
scoop install extras/abdownloadmanager
```

#### Homebrew (dla macOS i Linuxa)

```bash
brew tap amir1376/tap && brew install --cask ab-download-manager
```
