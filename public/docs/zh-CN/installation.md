## 安装

您可以通过以下方式安装 AB 下载管理器

### 直接下载

- [官方网站](https://abdownloadmanager.com/#download)：直接下载最新稳定版。对于大多数用户而言，这是最简单的方式。
- [GitHub 发布页面](https://github.com/amir1376/ab-download-manager/releases/latest)：包含安装程序和完整的发布历史记录。

### 安装脚本

#### Linux（推荐）
```bash
curl -fsSL https://raw.githubusercontent.com/amir1376/ab-download-manager/master/scripts/install.sh | bash
```

### 包管理器

#### Windows

##### Winget

```bash
winget install amir1376.ABDownloadManager
```

##### Scoop：

```bash
scoop install extras/abdownloadmanager
```

#### Homebrew（适用于 macOS 和 Linux）

```bash
brew tap amir1376/tap && brew install --cask ab-download-manager
```
