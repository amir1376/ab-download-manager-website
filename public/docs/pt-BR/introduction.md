# Introdução

Boas-vindas à documentação do AB Download Manager!

O AB Download Manager é um gerenciador de downloads gratuito, rápido e de código aberto, desenvolvido para tornar o download de arquivos uma tarefa simples, organizada e extremamente rápida.

## Principais recursos

- **Downloads rápidos:** Acelera os downloads em até 500% usando conexões com múltiplas threads.
- **Gerenciamento de filas:** Permite baixar vários arquivos em sequência por meio de filas de download personalizadas.
- **Interface moderna:** Oferece uma interface bonita e moderna, com suporte integrado ao modo escuro.
- **Integração com navegadores:** Captura automaticamente links de navegadores populares (Chrome, Firefox, Edge, Opera etc.) por meio de extensões.
- **Limitador de velocidade:** Permite controlar a largura de banda utilizada pelo aplicativo para evitar lentidão na rede.
