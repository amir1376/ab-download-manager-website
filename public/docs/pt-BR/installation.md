## Instalação

Você pode instalar o AB Download Manager das seguintes maneiras:

### Download direto

- [Site oficial](https://abdownloadmanager.com/): Baixe diretamente a versão estável mais recente. Essa é a opção mais simples para a maioria dos usuários.
- [Versões no GitHub](https://github.com/amir1376/ab-download-manager/releases/latest): Disponibiliza os instaladores e o histórico completo de versões.

### Script de instalação

#### Linux (recomendado)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amir1376/ab-download-manager/master/scripts/install.sh)
```

### Gerenciador de pacotes

#### Windows

##### Winget

```powershell
winget install amir1376.ABDownloadManager
```

##### Scoop

```powershell
scoop install extras/abdownloadmanager
```

#### Homebrew (macOS e Linux)

```bash
brew tap amir1376/tap && brew install --cask ab-download-manager
```
