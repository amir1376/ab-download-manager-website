# 简介

欢迎阅读 **AB Download Manager** 文档！

AB Download Manager 是一款免费、快速且开源的下载管理器，旨在让文件下载过程流畅、有序且迅如闪电。

## 主要功能

- **高速下载**：通过多线程连接，将下载速度提升高达 500%。
- **队列管理**： 通过创建自定义下载队列，依次下载多个文件。
- **简洁界面**：体验美观现代的用户界面，内置深色模式支持。
- **浏览器集成**：通过扩展程序自动从主流浏览器（Chrome、Firefox、Edge、Opera 等）捕获链接。
- **速度限制器**：控制应用程序占用的带宽，避免拖慢网络速度。
