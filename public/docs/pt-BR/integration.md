# Integração com navegadores

Integrar o AB Download Manager ao navegador permite capturar automaticamente os links de download, proporcionando uma experiência mais prática.

## Navegadores compatíveis

O aplicativo oferece suporte a navegadores modernos, incluindo:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Brave
- Opera
- Vivaldi

## Etapas de instalação

1. Instale a extensão correspondente ao seu navegador pela loja oficial de extensões ou pelos links disponíveis na janela de downloads do aplicativo.
2. Verifique se o aplicativo AB Download Manager está em execução em segundo plano no computador.
3. Depois de ativada a integração, os links de download em que você clicar no navegador serão encaminhados automaticamente para o AB Download Manager.
